# alceix-ecomeerce

## Proje yapısı

- `frontend/`: Next.js uygulaması (TypeScript, App Router, Tailwind CSS, ESLint).
- `backend/`: Backend geliştirmesi için ayrılmış klasör. Henüz bir framework kurulmadı.

## Frontend'i çalıştırma

```bash
cd frontend
npm install
npm run dev
```

Uygulama: http://localhost:3000

## Kontroller

`frontend` klasöründe:

```bash
npm run lint
npm run build
```
