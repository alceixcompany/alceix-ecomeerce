# Alceix Blog

/blog: kategori ve metin aramasıyla yazı listesi. /blog/[slug]: özgün rehber, içindekiler ve ilgili yazılar. Bilinmeyen yazılar 404 döner. İçerikler data/posts.ts içinde tutulur; harici CMS henüz bağlı değildir. Okuma süresi kelime sayısından hesaplanır. Yazılar mağaza hazırlığı ve ürün sunumu hakkında genel editoryal içeriktir. Kullanılan ürün/depo görselleri mevcut yerel örnek varlıklardır.
