# Influencer partner page

Route: `/influencer-ol`. The application anchor is `#influencer-form`.
Uses the shared marketing header, footer, typography and partner logos. Sections follow the supplied influencer portal reference; images are served locally from `public/influencer`.

The dedicated and compact home forms submit to the applications module API. Acknowledged submissions persist as pending records with an ID; account creation and partner approval do not occur. Shared form handling prevents repeat submission and preserves inputs on failure.

The statistics, testimonials, commission ranges and program terms reproduce the supplied reference content; they are static and require business confirmation before production publication.
